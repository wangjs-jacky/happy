# AgentParty 群聊可交互重建稿

文件：`agentparty-group-chat.html`。单文件、零外部依赖，可直接离线打开。

本稿按原版三栏信息结构及后续亮色偏好重建，不是已丢失原 HTML 的恢复。
仅演示交互，不连接 Paws，不读取账号或真实设备，不调用模型。
所有消息、配置、图片仅存于当前页面内存，刷新重置。

## 可操作内容

- 左栏切换群聊、创建群聊、Agent 管理；中栏发言与输入；右栏角色与执行配置。
- 编辑 Agent 名称、角色、头像、示例设备、目录、模型及联动思考强度。
- 群聊使用邀请时的配置快照。修改默认配置只影响之后邀请/新建的成员。
- 邀请已有 Agent；创建仅在当前群存在的临时成员。
- 输入 @ 多人，上传或粘贴图片，预览和移除附件；Enter 发送、Shift+Enter 换行。
- 自动接话开关；关闭时未点名的消息仅进入记录。
- 执行详情弹窗展示明确标注的模拟流程，不伪造真实日志。

不覆盖真实能力发现、模型推理、自动辩论调度、Paws 预设导入、运行中配置热更新。
