状态：部分完成，整体未完成。新版代码与自动检查已完成；真实浏览器视觉验收和截图交付受阻，未上线。

## 设计依据

用户最新三张截图分别作为新建胶囊、保存气泡和聊天预览的依据。保留 Paws 的文件阅读与聊天框布局，不以之前的网页原型或第二版侧栏作为本轮样式标准。

- 选区附近使用单行圆角胶囊，细边框、轻阴影、左侧小图标、右侧圆形勾选；去掉文件批注的标题、路径说明、关闭叉号、引文块、textarea 和文字保存/取消按钮。
- 保存后显示从 1 开始的编号与纯文字气泡；活动原文高亮。点击气泡编辑，点击空白关闭。
- 聊天计数上方显示小缩略、所选文本、意见正文及编辑/删除图标；移除独立文件批注侧栏。
- 各交互表面采用主题语义色；胶囊、气泡、编号、计数和预览条目具有轻微悬浮缩放，并尊重减少动态效果设置。
- 单行输入使用 Enter 或勾选保存；中文输入法组词阶段不提交。新建空白关闭不产生空批注。
