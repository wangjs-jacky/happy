# 全局会话悬浮窗

基线：943f0e0ca2c7ff3511490fa58db876e1f8273a9e。

## 实现与验收范围

- PC Web 侧栏插件按钮下增加全局会话开关；打开显示 ON，关闭移除 ON。
- 全局布局持有非模态窗口，默认约 360×560，标题栏拖动并约束于可见视口。
- 打开真实会话、离开项目页不会主动关闭窗口；显式关闭、开关或窗口内 Escape 可关闭。背景聊天 Escape 不受拦截。
- 保留需处理、执行中、待查看与连接未知分类及原有搜索；待查看沿用未读集合，真实会话可交互后由原阅读路径清除，不在点击时伪造已读。
- 固定项目筛选显示所属标题及全部项目清除入口，切换项目不错误标记为当前项目。
- Web 账号凭据切换重挂载窗口状态；原生平台的新增宿主为空包装，未新增原生会话面板。
