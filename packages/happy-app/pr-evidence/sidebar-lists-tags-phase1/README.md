# Sidebar Lists and Tags phase 1 visual evidence

Case `SIDEBAR-LISTS-TAGS` was captured by the isolated Web E2E harness in
Chromium, English, light theme, 1440x900, and DPR 1.

- Before: Projects remains the default desktop sidebar view and the current
  conversation is visible in the unchanged main workspace.
- After: the Lists tab restores two List types, one-to-many Tags, session
  organization, and the active conversation after a full page reload.

The pair comes from the same E2E case, viewport, seeded sessions, and browser
run. The right conversation and capability panels remain unchanged between the
two states.
